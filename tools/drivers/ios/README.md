# Apple 官方底层通信驱动组件 (iOS USB 驱动)

## 📌 概述
本目录收录了用于 Windows 系统的 Apple 官方 64 位独立底层通信驱动安装包 `AppleMobileDeviceSupport64.msi`。

该驱动用于在 Windows 系统中注册 `Apple Mobile Device Service` 系统后台服务（监听 `127.0.0.1:27015`），使桌面端审查器能够通过免管理员用户态加密隧道直接对接 iPhone 芯片级的 CoreDevice 硬件投屏与调试通道。

---

## 🚀 新电脑安装与使用

### 步骤 1：一键安装驱动
在当前目录下，鼠标右键点击 `install_driver.bat`，选择 **【以管理员身份运行】**（或直接双击，脚本会自动请求提权）。
脚本将在 **5 秒钟内静默完成驱动注册与服务启动**。

### 步骤 2：手机连接与授权
1. 用 USB 数据线将 iPhone 插入新电脑；
2. iPhone 屏幕亮起并弹出提示框时，点击 **【信任此电脑】** 并输入一次锁屏密码。

### 步骤 3：启动审查器投屏
在项目根目录启动审查器：
```bash
python -m desktop_app.ui.harmony_native_inspector
```
选中设备后点击 **【📺 开启实时投屏】**，即可享受 60 FPS 满帧流式直通。
