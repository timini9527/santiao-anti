## ✍️ 十、`docs/` 文档命名规范（后续新增请遵守）

1. **统一使用简体中文命名**：文件名直接体现“主题 + 文档类型”（如 `xxx架构设计方案.md`、`xxx搭建指南.md`、`xxx专项测试用例.md`），必要专有名词（如 `iOS`、`WDA`、`Appium`、`Charles`、`IM`）保留英文简称。
2. **禁止空格与中英文括号**：统一使用下划线 `_` 分隔编号、日期或补充标记（如 `_历史基线`、`_20261020`），确保 Markdown 相对链接免转义、一眼可读。
3. **按分类归档并同步目录**：新增文档放入对应 `01_ ~ 07_` 子目录后，同步登记到本 [README.md](README.md)。
