# 会员三期测试用例

本文覆盖会员三期“会员多档位周期扩容”和“会员功能设置”两部分需求，包含会员档位展示、个人购买、会员赠送、会员时长叠加、会员铭牌、个性昵称颜色、聊天气泡、头像挂件、非会员引导弹窗、聊天消息渲染、权益生命周期、动态配置、兼容迁移、异常安全和端到端回归场景。

除特别说明外，会员价格、档位、活动角标、装扮资源、权益文案和有效期均以服务端配置及最终 UI 设计为准；原有会员支付、赠送、铭牌和消息流程中未被本需求修改的部分，以线上版本为基线进行回归。

## 1. 测试范围、平台与基础数据

### 1.1 测试账号和数据

- U0：从未开通过会员的非会员账号。
- U1：会员有效期内的有效会员，未修改过新增装扮。
- U2：会员有效期内的有效会员，已设置昵称颜色、聊天气泡和头像挂件。
- U3：历史会员已过期账号，后台保留最近一次装扮配置。
- U4：会员即将到期账号，用于到期边界和续费竞态。
- U5：同一账号登录 iOS 和 Android 两台设备，用于多端同步。
- G1：可赠送会员的赠送方账号，G2 为可接收赠送的目标账号。
- C1：服务端返回多档位、多装扮和动态文案的正常配置。
- C2：空配置、重复配置、非法价格、非法颜色、下架档位和失效资源配置。
- M1：已有旧版本会员铭牌设置和历史会员时长数据的账号。

### 1.2 平台和通用状态

- 覆盖支持的 iOS、Android 系统版本，包含低端设备、小屏、异形屏、横屏、深色模式、大字体和 VoiceOver 或 TalkBack 环境。
- 覆盖正常网络、弱网、断网、请求超时、服务端 4xx、5xx、支付渠道异常和系统时间变化。
- 未明确的最终固定文案、档位价格、赠送限制、会员中心菜单顺序和装扮资源字段，在文末“需求待确认项”中列出。

## 21. 需求待确认项与测试准备

1. 会员档位最终清单：除原型中的 1、3、6 个月外，是否还有其他周期；每个档位的商品 ID、有效期、售价、原价、促销角标和上下架状态分别是什么。
2. 默认档位策略：服务端未返回 1 个月档位时，是否默认选中最短可售档位；无可售档位时页面、按钮和空状态的最终表现是什么。
3. 有效期计算方式：按自然月、固定天数还是服务端统一时间戳计算；月底、闰年、时区切换和有效期边界如何处理；叠加购买的起算点和是否存在有效期上限是什么。
4. 有效会员购买规则：有效期内是否始终允许自购或续费；待支付订单是否限制数量；同一档位重复购买、不同档位连续购买如何处理。
5. 赠送规则：赠送入口的准确位置、目标用户限制、是否允许自赠、向有效或过期会员赠送的叠加规则，以及目标账号注销、封禁、拉黑或注销中的处理方式。
6. 支付口径：各支付渠道、协议勾选、取消、失败、订单异常、退款和回调补偿的最终文案、状态机和回跳路径；支付成功后是否强制回到会员中心或原设置页。
7. 会员中心入口：自购和赠送入口的准确布局、会员有效期内的按钮文案，以及购买记录入口是否需要展示档位、促销和赠送信息。
8. 会员功能设置菜单：最终菜单顺序、标题、说明文案、会员中心顶部铭牌状态的展示样式，以及过期会员是否可以查看全部设置项。
9. 隐藏会员铭牌：到期时开关状态是否保持用户最后设置；本人视角、他人视角、消息列表、系统通知和历史缓存中的具体展示规则是什么。
10. 昵称颜色范围：最终支持的颜色清单、名称、色值和深色模式适配；颜色是否仅在点击“确认”后保存；点击系统默认黑色是否属于可修改操作。
11. 颜色生效场景：个人资料、群成员、聊天消息、消息列表、搜索结果、推送通知、评论或其他昵称场景的完整清单，以及是否存在强制展示或强制黑色的特殊页面。
12. 非会员通用提示弹窗：次按钮最终统一为“取消”还是“返回”；是否始终提供“会员功能设置”入口；点击弹窗外、系统返回键和支付取消后的返回路径分别是什么。
13. 过期会员引导：过期会员点击颜色、气泡、挂件和铭牌操作时，统一使用非会员通用提示、续费引导还是独立过期弹窗；各入口的按钮和跳转状态是什么。
14. 聊天气泡和头像挂件：资源字段、类型枚举、预览数据、缩略图尺寸、动态配置下发方式、缓存时长、版本号、灰度策略和资源下线策略是什么。
15. 装扮列表权限：非会员是否可以查看全部会员专属资源、是否显示锁定态或价格；会员到期后当前使用项、列表选中项和历史配置的具体展示规则是什么。
16. 装扮互斥关系：气泡和挂件是否各自只能有一个使用中；系统默认项切换是否需要服务端请求；重复点击、并发点击和接口失败时的最终状态是什么。
17. 气泡消息协议：扩展字段名称、数据类型、版本和大小限制；适用的消息类型；转发、回复、收藏、编辑、重发、漫游、撤回和多端同步是否保留原气泡字段。
18. 消息展示规则：系统通知、消息列表预览、搜索结果、未读摘要和历史消息是否展示气泡效果；新旧客户端互通时的明确降级样式是什么。
19. 头像挂件生效规则：本人、他人、群成员、聊天列表、搜索结果、系统通知和缓存头像中的覆盖范围；挂件是否随会员到期立即隐藏或回退默认。
20. 生命周期保留策略：会员到期后后台历史最新配置保留多久；用户注销、退款、账号迁移、清除 App 数据和删除账号时是否保留或清除配置；历史资源下线时如何恢复。
21. 多端冲突策略：同一账号不同设备同时修改同一或不同类型权益时，采用版本号、最后写入、服务端合并还是其他规则；同步通知和刷新时延目标是多少。
22. 账号与设备安全：退出登录、切换账号、卸载重装、新设备登录和系统备份恢复时的缓存清理、敏感数据存储和页面栈处理要求是什么。
23. 服务端接口约束：会员资格、档位、价格、时长、资源 ID、资源类型和用户归属的校验字段、错误码、幂等键、限流策略和审计字段是什么。
24. 支付与赠送对账：回调验签、重复回调、入账失败补偿、退款回滚、赠送入账延迟和订单状态查询的 SLA、告警和人工处理流程是什么。
25. 平台范围：iOS、Android 的最低支持版本、平板和横屏支持范围、深色模式、系统字体放大、VoiceOver/TalkBack 适配等级以及低端机性能指标是什么。
26. 网络和缓存策略：断网时会员状态、价格、装扮列表和配置操作的展示优先级；本地缓存的有效期、失效策略、重试次数和是否允许离线预览是什么。
27. 文案与国际化：所有固定文案、动态文案、金额格式、日期格式、协议名称和按钮翻译清单；长文案、占位符缺失和未翻译 key 的处理方式是什么。
28. 数据埋点：页面曝光、档位选择、支付发起、支付结果、提示弹窗、颜色确认、装扮预览、装扮使用、到期回退和恢复等事件名、参数、去重及隐私要求是什么。
29. 监控与发布：核心接口、支付回调、权益入账、资源加载和消息解析的监控指标、告警阈值、灰度范围、回滚方案和线上验证账号是什么。
30. 会员权益说明：会员中心权益介绍中的最终图标、标题、说明和排序；“个性昵称、聊天气泡、头像挂件”是否均作为独立权益展示，是否需要展示有效期或到期提醒。

### 21.1 测试执行建议

1. P0 用例作为提测准入和发布阻断项，必须在 iOS、Android 和至少一套支付渠道上通过；P1 用例纳入完整回归；P2 用例按版本风险和设备资源安排执行。
2. 购买、赠送、退款和回调用例优先使用沙箱商品和可回滚测试账号，验证订单、会员时长、配置记录、消息扩展字段和审计日志五类结果。
3. 涉及到期的用例使用可控服务端时间或分钟级测试商品，禁止仅修改客户端系统时间作为唯一结论；最终以服务端时间和订单状态验收。
4. 消息协议用例至少组合新版本发送方、新版本接收方、旧版本发送方和旧版本接收方四种客户端组合，并分别验证实时消息、漫游消息和离线推送场景。
5. 每次动态配置变更均应验证合法配置、空配置、字段缺失、资源下线、版本回滚和缓存刷新；变更前后记录配置版本和测试账号状态。
