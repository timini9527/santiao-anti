# 基础优化测试用例文档

本文覆盖基础优化需求中视频播放优化、外部文件分享到三条、GIF 动图发送、我的收藏搜索与收藏文本复制、视频美颜设置及视频通话结束引导等功能，包含主流程、边界、异常、权限、数据安全、平台兼容、性能、埋点和端到端回归场景。

除特别说明外，媒体资源、视频时长、文件大小、视频美颜默认参数、页面文案和控件样式均以服务端配置及最终 UI 设计为准；原有聊天、文件消息、表情、收藏、视频通话、系统分享和权限流程中未被本需求修改的部分，以线上版本为基线进行回归。

## 1. 测试范围、平台与基础数据

### 1.1 测试账号和数据

- U0：正常登录用户，可进行单聊、群聊、收藏和视频通话。
- U1：好友关系正常的接收方账号，用于验证文件、GIF、视频和转发消息。
- U2：拥有大量收藏内容的账号，包含文本、图片、视频、GIF、文件、音频和不同昵称的收藏记录。
- U3：无收藏内容、无本地媒体缓存的新账号。
- U4：已拒绝或未决定相机权限的账号。
- U5：同一账号登录 iOS 和 Android 两台设备，用于配置、消息和媒体兼容验证。
- V1：可自动加载且已缓存首帧的正常视频。
- V2：未自动加载、需点击播放的正常视频。
- V3：长视频、短视频、高清和低清视频，以及不同方向的视频。
- V4：损坏、截断、无首帧、无音轨、无视频轨或不支持编码的视频。
- G1：不超过 10M 的 GIF，G2 为恰好 10M 的 GIF，G3 为超过 10M 的 GIF。
- F1：PDF；F2：Word 文件，包含 .doc 和 .docx；F3：Excel 文件，包含 .xls 和 .xlsx；F4：PPT 文件，包含 .ppt 和 .pptx；F5：MP3；F6：MP4；F7：TXT。
- C1：正常网络、正常媒体服务、正常文件权限和可用存储空间。
- C2：弱网、断网、请求超时、服务端 4xx 或 5xx、媒体资源失效、磁盘空间不足和系统权限拒绝。

### 1.2 平台和通用状态

- 覆盖支持的 iOS、Android 系统版本，包含小屏、异形屏、平板、横屏、深色模式、大字体、VoiceOver 和 TalkBack 环境。
- 覆盖 App 冷启动、热启动、前后台切换、系统回收、账号切换、退出登录、卸载重装和版本升级。
- 涉及“最终 UI”“默认值”“本期忽略”或“按现有逻辑”的项目，需在执行前确认产品与研发的最终验收口径。
